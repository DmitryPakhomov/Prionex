# Решение о релизе

Релиз заблокирован из-за BUG-003: Cash on Delivery нельзя подтвердить. Сохранение счёта через UI не проверено.

Повторный прогон: 13 тестов, 6 passed / 7 failed, 3 workers. [Финальный HTML-отчёт](reports/html/index.html) · [Текстовые контексты падений](reports/results/).

Пройдены поиск, пустая выдача API и UI, добавление с проверкой цены карточки, неверный пароль с сохранением корзины и обязательность адреса. BUG-001–BUG-005 воспроизведены; новые BUG-006 — отсутствие списка взносов, BUG-007 — реквизиты не сбрасываются.

BUG-004 доказывает ошибочный ответ проверки метода, не создание заказа. BUG-002 доказывает ошибку отображения строки, не итог сохранённого счёта.

После исправления блокера выполнить добавленные проверки GET счёта и пустой корзины. Затем ORD-03, PAY-06/07, границы количества, скидку и оставшиеся сценарии каталога и оплаты. Недостигнутые ветки автотеста пока не проверены исполнением.
