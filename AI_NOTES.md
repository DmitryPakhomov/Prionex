# Работа с AI

Использован Codex Desktop. Точное имя модели в экспортируемых событиях не подтверждено. Другие AI-инструменты и автодополнение в этой работе не зафиксированы.

| Экспорт | Содержание | Результаты |
| --- | --- | --- |
| [codex-01.json](ai_sessions/codex-01.json) | Основной журнал, включая команды и результаты инструментов, неудачные попытки и исправления | Развёртывание, планы, тест-кейсы, Playwright, отчёт, дефекты и решение о релизе |
| [codex-02.json](ai_sessions/codex-02.json) | Снимок продолжения чата о подключении и чтении задания | Контекст выбора репозитория и исходный план |
| [codex-03.json](ai_sessions/codex-03.json) | Снимок продолжения чата о версии и установке окружения | Выбранный спринт, коммит и команды запуска |
| [codex-04.json](ai_sessions/codex-04.json) | Снимок продолжения чата о развёртывании и QA-этапах | Проверка стенда и переход к тестированию |
| [codex-05.json](ai_sessions/codex-05.json) | Продолжение основного журнала, расширение покрытия | Удаление товара, неверный пароль, обязательный адрес и повторный прогон |
| [codex-06-review.json](ai_sessions/codex-06-review.json) | Независимое ревью, доработка и повторный прогон | Уточнения кейсов и проверок, BUG-006 и BUG-007 |
| [codex-07-security.json](ai_sessions/codex-07-security.json) | Сверка опубликованного коммита и очистка материалов | Поиск чувствительных данных в Git, экспортах и вложениях отчёта |

Пользователь подтвердил версию, выполнил вход в GitHub CLI и установил окружение в Windows. Codex проверил доступность UI и API, сверил ожидания с историями Sprint 5, написал проверки и воспроизвёл результаты в Chromium и через локальный API. Результаты сверены с финальным отчётом и trace. В частности, ошибочный прямой URL карточки в первом прогоне заменён переходом через каталог. При разборе заказа trace показал, что кнопка была отключена. Поэтому дефект описывает невозможность подтвердить заказ, а не ошибку после отправки платежа.

Экспорты в JSON собраны из событий, доступных в локальных журналах Codex Desktop. Основной файл содержит сообщения и вызовы с результатами, дополнительные файлы содержат сохранённые снимки с частичным дублированием. Внутренние служебные записи и данные модели в пользовательский экспорт не включены. Прикреплённые изображения представлены в том виде, в каком их сохранил журнал. Отдельный пробный экспорт до разработки не выполнялся. Четыре первоначальных JSON проверены на чтение и число событий. Экспорт фиксирует историю на момент создания файлов, поэтому завершающий ответ и команды после снимка в него не входят.

Маскированы одноразовые коды входа, строки, похожие на токены, пути профиля и рабочей папки, логины и идентификатор GitHub. Для маскирования заменены значения, а содержащие их сообщения и вызовы сохранены.

Дополнительные экспорты проверены на чтение. В codex-05.json также замаскированы сгенерированные учётные данные тестовых покупателей, попавшие в вывод инструментов.

В экспорте ревью замаскированы пути профиля и JWT. Завершающий ответ после снимка журнала отсутствует.

При финальной проверке дополнительно замаскированы имена аккаунтов, локальные пути, одноразовые коды и учётные данные тестовых пользователей в экспортах, trace и встроенных данных HTML. Метаданные финального коммита используют адрес GitHub noreply. Журнал проверки сохранён до публикации исправленного коммита.
