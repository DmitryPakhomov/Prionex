# Тест-кейсы Toolshop

Предусловие для всех кейсов — локальный `sprint5-with-bugs` на коммите из README с заполненной базой. UI-кейсы начинают с нового контекста браузера. Гость и покупатель используют пустую корзину, если не указано иное. Для негативного входа используется отдельный покупатель. Источник ожидаемого поведения — истории Sprint 5 и матрица функций.

## Уточнённые данные и покрытие

Повторный прогон: 13 тестов, 6 passed / 7 failed. Combination Pliers без скидки, stock >= 10. Цена API сверяется с карточкой. Адрес: 12 Test Street, Boston, MA, US, 02108. Покупатель создаётся API с уникальной почтой; UI регистрация не покрыта.

CAT-04: взять category_id и brand_id Combination Pliers через API и выбрать соответствующие названия фильтров. PAY-01: карта 4111-1111-1111-1111, 01/2020, CVV 123, Taylor Smith. PAY-02: Bank Transfer — Test Bank, Taylor Smith, 1234567890; Gift Card — GIFT123, CODE123. Каждое обязательное поле очищать отдельно при заполненных остальных. PAY-04: Taylor Smith / 1234567890, Bank Transfer → Gift Card → Bank Transfer.

ORD-01 дополнен GET /invoices/{id}: номер, владелец, строки, цены, количество и итог; после reload требуется явное состояние пустой корзины. Эти проверки пока не достигнуты из-за BUG-003. ORD-02 подтверждает блокировку перехода, но отдельное сообщение валидации не проверяет. CAT-05 не достиг межстраничной части.
